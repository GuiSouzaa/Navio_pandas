# 📊 Navio Pandas
Este projeto é uma aplicação web desenvolvida com Flask que permite ao usuário fazer o upload de uma planilha Excel e com base em uma planilha de referência, gera uma nova planilha formatada conforme as especificações definidas.

## 🧰 Tecnologias Utilizadas
Python: Linguagem principal utilizada no backend.

Flask: Framework web utilizado para criar a aplicação.

Pandas: Biblioteca para manipulação e análise de dados.

HTML/CSS/JavaScript: Tecnologias utilizadas no frontend para a interface do usuário.

## 📁 Estrutura do Projeto
app.py: Arquivo principal que inicia a aplicação Flask.

Base_de_dados/: Contém a planilha de referência utilizada para formatar os dados.

static/: Contém arquivos estáticos como CSS e JavaScript.

templates/: Contém os arquivos HTML que definem a interface da aplicação.

flask.txt e original.txt: Arquivos de configuração e referência.

## ⚙️ Funcionalidades
Upload de planilhas Excel pelo usuário.

Processamento e formatação dos dados com base em uma planilha de referência.

Geração de uma nova planilha formatada para download.
